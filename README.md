# 叠个饭

小蚕、歪麦霸王餐与美团试吃官同店比价工具，支持活动同步与返现试算。

## 功能特性

| 功能 | 支持范围 |
| --- | --- |
| 账号连接 | 小蚕登录或访客请求会话、歪麦 token 或访客访问、美团远程登录或本人浏览器会话导入 |
| 活动同步 | 首次打开及每 5 分钟自动同步，按同一收餐地址分页比较 7 公里内活动 |
| 地址获取 | 浏览器自动定位城市、行政区与经纬度，支持重新定位与手动填写 |
| 叠加组合 | 小蚕 + 美团、歪麦 + 美团 |
| 同店匹配 | 门店 ID、完整分店名与待核验候选 |
| 金额展示 | 固定返现、比例返现、评价加返、门槛与独立上限 |
| 活动管理 | 筛选、排序、CSV 导出 |
| 界面 | 桌面与移动端尺寸适配 |
| 局域网调试 | 显式启用、本机与私网访问、同源请求校验 |

## 技术栈

| 层级 | 技术 |
| --- | --- |
| 应用 | Nuxt 4、Vue 3、TypeScript |
| 服务端 | Nitro、Node.js |
| 远程登录 | Playwright Core、Google Chrome、会话隔离的实时画面与输入 |

| 会话存储 | AES-256-GCM 加密文件 |
| 开发工具 | tsx、vue-tsc、Prettier |

## 环境要求

- Node.js 22 或更高版本、npm。
- 运行服务的电脑需要安装 Google Chrome，用于美团远程登录与活动同步。
- 默认通过 `localhost` 或 `127.0.0.1` 访问；局域网调试可显式开启。

## 安装与快速开始

```bash
npm install
npm run dev
```

访问 [http://127.0.0.1:3000](http://127.0.0.1:3000)。首次访问允许浏览器定位以自动保存收餐位置，在「账号管理」连接平台后，在「首页」同步活动。已有地址保留不变，可在地址设置中选择「使用当前位置」重新定位。

自动定位使用设备当前位置与 BigDataCloud 的客户端逆地理编码接口，无需配置 API 密钥；识别城市、行政区和位置名称，并转换为平台使用的 GCJ-02 经纬度，不识别门牌号。定位不可用时支持手动填写。浏览器定位需要安全上下文：本机 `localhost` 可用，局域网 IP 通常需 HTTPS。

生产运行：

```bash
npm run build
npm start
```

### 局域网调试

```bash
npm run dev:lan
```

在同一局域网设备访问 `http://<运行电脑的局域网 IP>:3000`。局域网模式绑定 `0.0.0.0`，API 允许本机与私网 IP，保留同源请求校验与浏览器会话隔离。仅在可信局域网启用，不要配置公网端口转发。

生产构建可使用 `npm run start:lan`。`npm run dev` 与 `npm start` 仍使用本机模式。美团登录页面显示在访问设备的网页内，不打开服务端桌面窗口。

## 账号连接

### 小蚕霸王餐

将本人微信小蚕小程序 `https://gw.xiaocantech.com/rpc` 请求的原始请求头、请求头 JSON 或 cURL 粘贴到「账号管理」的小蚕会话输入框，选择「保存会话」。请求需要 `X-Teemo`、`X-Vayne` 及相应会话字段；无需手动拼接请求体，收餐地址与请求参数由应用生成。

支持 `X-Teemo`、`X-Vayne` 同为 `0` 的访客请求，无需提供 `X-Sivir`。保存后显示「访客待验证」，同步成功后显示「访客访问」；访客请求不代表账号已登录。

当前支持小程序会话导入，未接入小蚕原生短信或微信授权登录。参考项目的用户登录属于其自建服务，不是小蚕官方登录。

### 美团试吃官

在「账号管理」选择「打开登录页面」，在网页内操作美团官方账号登录页，完成短信登录与安全验证后选择「验证登录」。登录入口不依赖活动页面加载。支持点击、拖动、键盘输入与滚动；手机或中文输入可使用画面下方的输入框。会话失效后需重新登录，安全校验由官方页面处理。

远程登录会话有效期为 15 分钟，按访问浏览器隔离。关闭登录界面释放对应浏览器；验证成功后会话加密保存，用于后续同步。

账号登录与活动连接分别验证。官方账号登录成功但活动接口拒绝访问时，保留登录会话并显示活动连接失败；后续可重新同步。活动连接成功前不会标记为已连接。

远程登录可能被美团拒绝，表单能够显示不代表短信发送或登录一定可用。出现拒绝时，选择「浏览器登录」在当前设备的普通浏览器完成官方登录，再打开「会话导入」中的「试吃官页面」。在该页开发者工具的网络面板复制本人 `/act/ge/getUserInfo` 或 `/act/ge/queryPoiByRecallBiz` 请求的 cURL（bash 格式），粘贴并保存会话，最后验证登录。

会话导入也接受 Cookie 请求头和请求头 JSON，不执行粘贴的命令。导入后为待验证状态，只有官方身份检查通过才标记为连接成功。导入凭据加密保存，不会保证服务端网络能访问活动接口；会话内容属于账号凭据，请勿发到聊天或公开分享。

### 歪麦霸王餐

在「账号管理」导入本人歪麦小程序请求头中的 `token`，支持直接粘贴 token 或请求头 JSON；也可选择「启用访客访问」。保存收餐地址时填写城市名称（如 `上海市`），在「首页」选择「歪麦」后同步。

歪麦分页同步美团外卖霸王餐活动，包含门槛、普通用户返现、剩余名额、有效时段与评价要求。会员补偿不计入普通用户返现；歪麦内的美团赏金不作为额外霸王餐返现参与叠加。歪麦内部门店 ID 不用于跨平台确认分店。

## 金额展示

收支试算 = 所选霸王餐平台返现 + 美团折算返现 − 订单金额。默认按霸王餐要求金额试算，指定商品同时满足商品价格；结果为正显示「预计收益」，为负显示「预计支出」，为零显示「收支平衡」。

卡片、筛选与排序按活动规则试算，尚未开始的活动也保留规则返现。返现校验金额门槛，比例返应用金额上限。

美团活动提供评价加返时，试算与排序包含该奖励，基础返现与评价奖励分别应用各自上限。未提供评价奖励的活动不增加返现。

页面首次打开时同步一次，保持打开期间每 5 分钟自动同步所选霸王餐平台与美团活动。需先连接平台并设置收餐地址；同步进行中跳过重复请求，手动同步保留 30 秒间隔限制。同步失败保留上次成功数据。

同店同商品的不同活动档位合并为一张卡片，分别展示订单金额、返现与收支试算。CSV 导出保留每个活动档位。

同步按平台分页继续获取至列表结束，合并重复活动，并保留距收餐位置 7 公里内的数据。分页失败或未完整加载时保留上次成功数据，不将部分结果标记为同步成功。可见列表仍受有效时段、名额、筛选与同店匹配结果影响。

小蚕指定商品活动保留商品名称和活动价格，试算同时满足活动门槛与商品价格。

## 配置

环境变量模板见 [.env.example](.env.example)。

| 环境变量 | 用途 | 默认值 |
| --- | --- | --- |
| `FOOD_BROWSER_PATH` | Chrome 可执行文件路径 | 使用已安装的 Google Chrome |
| `FOOD_DATA_DIR` | 加密会话文件目录 | `.data/food` |
| `FOOD_ALLOW_LAN` | 值为 `1` 时允许局域网 API 请求 | `0` |

生产入口从启动环境读取变量，不自动加载 `.env`。会话目录内的密钥和加密文件需共同备份。
